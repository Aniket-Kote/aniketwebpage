# Personal Portfolio Website

This is a personal portfolio website for Aniket Kote, a Data Analyst and RPA Developer. The website showcases his projects, skills, and experiences in Data Science, Automation, and Analytics.

## Technologies Used

* HTML
* CSS
* JavaScript

## Overview

The website is a single-page application that includes the following sections:

*   **About Me:** A brief introduction to Aniket and his skills.
*   **Featured Projects:** A collection of his most prominent projects with links to GitHub repositories and demo videos.
*   **Tech & Creative Stack:** A list of his technical and creative skills.
*   **Experience:** A summary of his professional experience.
*   **Education:** His educational background.
*   **Contact:** Contact information.

The website is designed to be responsive and visually appealing, with a clean and modern design. It also includes a scroll-to-top button for easy navigation. The other HTML files in the repository appear to be drafts or templates and are not part of the main website.
